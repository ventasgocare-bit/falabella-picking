# Falabella Picking

Automatización para procesar manifiestos PDF de Falabella Seller Center.

## Funcionalidades

* Lee PDF de manifiesto Falabella.
* Extrae órdenes, seguimiento y cantidad.
* Calcula últimos 4 dígitos.
* Ordena automáticamente.
* Genera:

  * PDF de picking
  * Excel de respaldo

## Uso

```bash
python3 falabella_picking.py ruta_del_pdf.pdf
```

## Salida

Los archivos se guardan en:

~/Documents/Salidas Falabella
